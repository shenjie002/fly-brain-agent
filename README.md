# FlyBrain Agent

> A closed-loop web demo: **Laya fast-brain decision → spiking neurons (LIF) → 3D fly motion**.
> The fly model comes from FlyGym (NeuroMechFly v2); physics runs in-browser via MuJoCo WASM.
>
> 一个 Web 闭环 Demo：**Laya 快脑决策 → 神经放电 (LIF) → 果蝇 3D 运动**。
> 果蝇模型来自 FlyGym (NeuroMechFly v2)，物理由浏览器内 MuJoCo WASM 驱动。

## English

### What is this?

FlyBrain Agent turns a language-model decision into real spiking-neuron activity
that drives an embodied 3D fruit fly. It ships **two front-end pages** that share
the same backend and the same 3D fly:

- **game.html** — a free race track; the fly walks across it autonomously using a
  CPG hexapod gait.
- **flappy.html** — *FlyBrain Flappy*; the fly's motor neurons "pilot" a Flappy Bird.

### Architecture

```
Browser (brain-game/)                    Python backend (pipeline.py :8000)
┌──────────────────────┐                ┌──────────────────────┐
│ MuJoCo WASM physics  │  POST /decide  │ Laya fast-brain      │
│ Three.js fly render  │ ◄────────────► │ LIF spiking (motor)  │
│ CPG hexapod control  │                │ motor-command decode │
│ Neural HUD panel     │                └──────────────────────┘
└──────────────────────┘
```

### The closed loop

```
bird position → English scene sentence → Laya decision (FLAP/HOLD)
  → 13 LIF motor neurons spike → fly kicks left/right legs
  → light up UP/DOWN button → lift impulse / gravity fall → bird flies
```

### What is LIF? (Leaky Integrate-and-Fire)

The most classic spiking-neuron model. Think of a neuron as a leaky cup:

- **Integrate** — inputs raise the "membrane potential" (water level), starting at -65mV.
- **Leak** — with no new input the level decays back toward rest via `decay=exp(-dt/tau)`,
  so ancient inputs don't accumulate forever (`v = v*decay + R*(I+synaptic)`).
- **Fire** — once the level crosses threshold (-50mV) the neuron emits a spike (outputs 1)
  and is instantly reset, then starts filling again.
- Neurons are wired by a connectivity matrix `W`: a spike travels through synapses
  (`W @ spikes_prev`) to downstream neurons, forming the network.

In this project LIF is the translation layer between Laya's "thought" and the fly's
"action" — it makes *decision → action* actually run through neural dynamics instead
of an `if-else`. The flickering nodes in the brain map are these 13 LIF neurons
integrating and firing.

### Key modules

- **pipeline.py** — end-to-end FastAPI service (Laya + LIF + motor decode), `/decide`.
- **motor_map.py** — 13-neuron LIF network (4 wing + 2 haltere + 6 leg + 1 CMD) + decoder.
- **simulator.py** — `LIFSimulator` dynamics engine (`step` / `run`).
- **serve.py** — local dev server: COOP/COEP headers + `/decide` proxy to :8000.
- **shared/** — scene.js, controller.js (shared CPG gait), vendor (three.js + mujoco wasm).

### Install & run

```bash
cd fly-brain-agent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. backend
uvicorn pipeline:app        # → :8000

# 2. frontend (COOP/COEP + wasm mime + /decide proxy)
python serve.py             # → http://localhost:8090

# open game.html (race track) or flappy.html (FlyBrain Flappy)
```

> Note: `brain-game/assets/` (heavy STL + wasm game assets) are gitignored and
> regenerated by the build script. See DESIGN_NOTES.md for details.

### Honest boundaries

- The "UP/DOWN" in Flappy maps directly from Laya's `choice` to left/right legs,
  because FLAP only drives wings and HOLD is silent, so leg firing rates alone
  can't distinguish up from down.
- The ~335 nodes in the brain map are a visual enhancement; only the 13 real motor
  neurons actually make decisions. True hundreds of functional neurons (like the
  167k-neuron MaleCNS connectome) would require a larger backend neural model.

## 中文

### 这是什么？

FlyBrain Agent 把一个语言模型的决策，变成真实的脉冲神经元活动，再去驱动一具
有身体的 3D 果蝇。项目包含 **两个前端页面**，共用同一套后端和同一具 3D 果蝇：

- **game.html** — 自由赛道，果蝇用 CPG 六足步态自主穿越。
- **flappy.html** — *FlyBrain Flappy*，果蝇的运动神经"驾驶"一只 Flappy 小鸟。

### 架构

```
浏览器 (brain-game/)                     Python 后端 (pipeline.py :8000)
┌──────────────────────┐                ┌──────────────────────┐
│ MuJoCo WASM 物理     │  POST /decide  │ Laya 快脑            │
│ Three.js 果蝇渲染    │ ◄────────────► │ LIF 神经放电 (motor) │
│ CPG 六足控制器       │                │ 运动指令解码         │
│ 神经 HUD 面板        │                └──────────────────────┘
└──────────────────────┘
```

### 完整闭环

```
小鸟位置 → 编成英文情境句 → Laya 决策 (FLAP/HOLD)
  → 13 个 LIF 运动神经元放电 → 果蝇蹬左/右腿
  → 点亮 UP/DOWN 按钮 → 升力脉冲 / 重力下落 → 小鸟飞行
```

### LIF 是什么？(Leaky Integrate-and-Fire, 泄漏积分-发放)

最经典的脉冲神经元模型。把神经元看成一个会漏水的杯子：

- **Integrate(积分)** — 输入让"膜电位"(水位)上涨，初值 -65mV。
- **Leak(泄漏)** — 没有新输入时水位按 `decay=exp(-dt/tau)` 慢慢漏回静息值，
  防止久远输入无限累积 (`v = v*decay + R*(I+synaptic)`)。
- **Fire(发放)** — 水位越过阈值 -50mV 就发一个 spike(输出 1)，随即清零重来。
- 神经元之间由连接矩阵 `W` 相连：一个发放会经突触 (`W @ spikes_prev`) 把电流
  传给下游，构成网络。

在本项目里，LIF 是 Laya 的"想法"和果蝇"动作"之间的翻译层——它让
*决策 → 动作* 真的走一遍神经动力学，而不是一个 `if-else`。脑图上闪烁的节点，
就是这 13 个 LIF 神经元在积分-发放。

### 关键模块

- **pipeline.py** — 端到端 FastAPI 服务 (Laya + LIF + 运动解码)，`/decide`。
- **motor_map.py** — 13 神经元 LIF 网络 (4 翅 + 2 haltere + 6 腿 + 1 CMD) + 解码器。
- **simulator.py** — `LIFSimulator` 动力学引擎 (`step` / `run`)。
- **serve.py** — 本地 dev server：COOP/COEP 头 + `/decide` 反代到 :8000。
- **shared/** — scene.js、controller.js(共用 CPG 步态)、vendor (three.js + mujoco wasm)。

### 安装与运行

```bash
cd fly-brain-agent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. 起后端
uvicorn pipeline:app        # → :8000

# 2. 起前端 (COOP/COEP + wasm mime + /decide 反代)
python serve.py             # → http://localhost:8090

# 打开 game.html(赛道) 或 flappy.html(FlyBrain Flappy)
```

> 说明：`brain-game/assets/`(重型 STL + wasm 游戏资源)已被 gitignore，

### 诚实的边界

- Flappy 里的"上/下"是用 Laya 的 `choice` 直接映射左/右腿的，因为 FLAP 只驱动
  翅膀、HOLD 全静默，光靠左右腿放电率区分不了上下。
- 脑图里约 335 个节点是可视化增强，真正做决策的只有那 13 个真实运动神经元。
  要真正上百个有功能的神经元(像 16.7 万神经元的 MaleCNS 连接组)，需要换更大的
  后端神经模型。
